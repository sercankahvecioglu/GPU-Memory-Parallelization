# Milestone 6: distributed lid-driven cavity MLUPS benchmark
# Source: bwUniCluster 3.0 strong-scaling runs (executables/milestone6 --benchmark)
# See notes: https://pastewka.github.io/Accelerators/notes/benchmarking.html
#
# Methodology (see executables/milestone6.cpp main(), --benchmark):
#   - 100 warmup timesteps run and discarded, then the fluid is reset to the
#     stationary initial condition so every repeat times the same problem.
#   - Kokkos::fence() + MPI_Barrier() precede the timer; Kokkos::fence() again
#     before it stops, so only completed device work is measured.
#   - MPI_Allreduce(MAX) takes the slowest rank's wall time as the run time.
#   - Global diagnostics and all I/O are outside the timed region.
#   - MLUPS = (nx * ny * steps) / seconds / 1e6, i.e. total lattice updates
#     across the whole distributed grid, one process/GPU per rank.
#   - Each configuration was repeated 3 times (data: milestone6_results/scaling/*/raw.csv);
#     median is reported, with the min-max range in brackets (single
#     executions are unreliable per the benchmarking notes).
